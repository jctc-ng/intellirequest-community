Import · Fill · Preview · Update Word files locally Browser edition

Private document handling: Your Word file is processed in this browser and is not uploaded to GitHub or any server. Use an authorized device and review every result before official use. The software contains no institutional template.

1. Open your own Word document

For direct updates to the original file, use the latest Chrome or Edge. The app can operate without Python or LibreOffice.

2. Fill in the fields

Values fill matching placeholders, such as {{EXCHANGE}} or {{OFFICER}}. For text already written in your document, add an exact Find/Replace rule. This works with content inside tables and headers too.

Replace existing wording across the document

3. Preview your updated document

The preview uses the imported Word document and retains many original styles, tables, headers and embedded images. Browser rendering may differ from Microsoft Word, particularly for pagination, floating objects, footnotes and complex layouts.

Change report and review reminders







Saving to the selected original creates a separate backup first and requests your permission. If your browser cannot update files directly, it will explain how to use Chrome or Edge.
